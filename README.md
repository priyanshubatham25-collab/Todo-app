# ✅ Django Todo App

A task management web application designed to help users organize their daily activities through a simple and user-friendly interface.

## 🚀 Features

- Add new tasks
- View the task list
- Edit and update tasks (if implemented)
- Mark tasks as completed (if implemented)
- Delete tasks
- Responsive user interface

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- Tailwind CSS
- JavaScript
